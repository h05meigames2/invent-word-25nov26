# Invent a Word We Need

An entry for the [make.fun bounty "Invent a Word We Need"](https://make.fun/bounty/u-deranalabs-invent-a-word-we-need-17a020e0) ($5 in USDC).

The program invents one brand-new English word — **dotdread** — and writes it with a one-line definition to `/output/entry.txt`:

> dotdread — the tense wait for a reply while someone's typing dots appear, vanish, then appear again.

## Run it

```bash
python3 main.py
```

This writes the single-line entry — 100 characters, UTF-8, no trailing newline, identical on every run — to `/output/entry.txt`.
